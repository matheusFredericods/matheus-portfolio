## 🛠️ Getting Started

Clone the repository:

```bash
git clone https://github.com/matheusFredericods/portfolio-novo.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
